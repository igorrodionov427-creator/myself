FAQ

Is custom software always expensive?

Not necessarily. We start with the smallest version that solves the main task and grow it step by step.

Who owns the code?

It’s agreed before we start and written down in the project terms.

Can you improve software built by someone else?

Yes. We review the code and tell you what can be done.

Shall we discuss your task?

Describe it in a couple of sentences — we’ll suggest how to build it and give a rough timeline.
